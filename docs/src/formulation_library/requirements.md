# [Requirement Formulations](@id requirement_formulations)

Formulations for requirements: policies that constrain several technologies together. A
requirement is a `PowerSystemsInvestmentsPortfolios.Requirement` in the `Portfolio`, and is
modeled with a [`RequirementModel`](@ref). See the
[Formulation Library](@ref formulation_library_intro) introduction for the nomenclature.

* * *

## `RequirementEnergyShare`

See [`RequirementEnergyShare`](@ref). Formulation for `EnergyShareRequirements`, such as a
renewable portfolio standard: over an investment period, the energy generated by a set of
contributing technologies must be at least a fraction of the demand of a set of
contributing demands.

A technology contributes to a requirement ``q`` when the requirement is in the
`requirements` field of the technology:

  - ``\mathcal{G}^\text{gen}_q``: contributing `SupplyTechnology`, `StorageTechnology`, and
    `ColocatedSupplyStorageTechnology` technologies that are available
  - ``\mathcal{G}^\text{dem}_q``: contributing `DemandRequirement` and
    `DemandSideTechnology` technologies that are available

Both sets must contain at least one technology, and every technology in
``\mathcal{G}^\text{gen}_q`` must have a technology model in the template.

**Static Parameters:**

  - ``S_q`` = `PowerSystemsInvestmentsPortfolios.get_generation_fraction_requirement(requirement)`
  - ``Y_q`` = `PowerSystemsInvestmentsPortfolios.get_target_year(requirement)`
  - ``i_q``: the investment period whose dates include the year ``Y_q``. It is an error if
    no investment period includes it.

**Time Series Parameters:**

  - ``D_{g,t}``: demand of each contributing demand, from the time series `"ops_demand"`

**Expressions:**

[`WeightedEnergyShareGeneration`](@ref), for each operational period, the sum of the
[`WeightedEnergyGeneration`](@ref) expressions of the contributing technologies:

```math
w^\text{gen}_{q,k} = \sum_{g \in \mathcal{G}^\text{gen}_q} W_k \sum_{t \in \mathcal{T}_k} p_{g,t}, \quad \forall k \in \mathcal{K}
```

For storage and co-located technologies, ``p_{g,t}`` is the net discharge
``p^\text{out}_{g,t} - p^\text{in}_{g,t}``.

[`WeightedEnergyShareDemand`](@ref), for each operational period, the weighted demand of
the contributing demands:

```math
w^\text{dem}_{q,k} = \sum_{g \in \mathcal{G}^\text{dem}_q} W_k \sum_{t \in \mathcal{T}_k} D_{g,t}, \quad \forall k \in \mathcal{K}
```

Both expressions are created for every operational period and are available in the
results.

**Constraints:**

[`EnergyShareRequirementConstraint`](@ref), one for each requirement, over the operational
periods of the investment period ``i_q``:

```math
\sum_{k \in \mathcal{K}_{i_q}} w^\text{gen}_{q,k} \ge S_q \sum_{k \in \mathcal{K}_{i_q}} w^\text{dem}_{q,k}
```

!!! note
    
    The requirement applies only to the investment period that contains its target year.
    To apply a share in several investment periods, add one requirement for each.
